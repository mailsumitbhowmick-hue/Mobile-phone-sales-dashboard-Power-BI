# Mobile-phone-sales-dashboard-Power-BI
n interactive Mobile Sales Dashboard developed using Microsoft Power BI to analyze mobile sales performance and customer behavior. This project demonstrates my practical knowledge of data visualization, business intelligence, dashboard development, and data analysis. 
Key Insights & Features
KPI Cards: Total Sales, Total Quantity, Total Transactions, and Average Price
Monthly Sales & Quantity Trends: Analyze sales performance across different months
City-wise Sales Analysis: Visualize sales distribution across different cities
Mobile Model Performance: Compare sales across different mobile models
Day-wise Analysis: Identify sales patterns by day of the week
Customer Ratings: Analyze customer rating distribution
Payment Method Analysis: Compare transactions across different payment methods
Brand-wise Performance: Compare sales and quantity across major mobile brands
Interactive Filters: Filter the dashboard by month, mobile model, customer-related fields, payment method, and brand
